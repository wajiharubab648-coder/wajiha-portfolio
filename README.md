## 📌 About

This portfolio highlights my journey as a backend-focused Python developer — from Django web applications to desktop tools and computer vision utilities. It's designed with a dark, modern UI and built entirely from scratch.

## ✨ Features

- Responsive, dark-themed UI with smooth scroll animations
- **Home** — introduction and quick links
- **About** — background, focus areas, and current goals
- **Skills** — organized by category (Languages, Frameworks & Libraries, Tools & Architecture)
- **Education** — academic background and key coursework focus
- **Projects** — featured and additional projects with source code links
- **Contact** — direct contact details plus a working contact form
- **Resume page** — full CV view with a downloadable PDF

## 🛠️ Tech Stack

- **Backend:** Python, Django
- **Frontend:** HTML5, CSS3
- **Database:** SQLite

## 🚀 Getting Started

Clone the repository and run it locally:

```bash
# Clone the repo
git clone https://github.com/wajiharubab648-coder/Portfolio.git
cd Portfolio

# Create and activate a virtual environment
python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # macOS/Linux

# Install dependencies
pip install -r requirements.txt

# Apply migrations
python manage.py migrate

# Run the development server
python manage.py runserver
```

Then open `http://127.0.0.1:8000` in your browser.
